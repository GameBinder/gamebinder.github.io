# Platform logos

Drop one official logo per platform here, named exactly as below. SVG is preferred; `steam.png` and `epic-games.png` are already included (to use SVG instead, change the file names in `index.html`). Until a file exists, the tile shows the platform initial.

steam.svg · epic-games.svg · gog.svg · ea-app.svg · ubisoft-connect.svg · battle-net.svg · xbox.svg

Get them from each company's official brand / press resources and follow their usage guidelines. Do not recolour or redraw them.
Tiles have a light frosted background so full-colour and dark logos are legible. If you use white logos, set `--logo-tile: rgba(20,20,24,.9)` on `.plat-grid` in `css/style.css`.

Included: all seven logos (steam, epic-games, gog, ubisoft-connect, battle-net, xbox as PNG; ea-app as SVG).
